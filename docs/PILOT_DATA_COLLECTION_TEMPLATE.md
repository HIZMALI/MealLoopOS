# Meal service recording sheet

Use this sheet to record **what happened**, including unknowns. It does not establish that MealLoop OS caused a reduction. No kitchen pilot has been established by this project. Use the kitchen's existing scale if available; special hardware, paid software and technical knowledge are not required. Without a scale, leave mass blank rather than inventing a reading.

## Before using the sheet

Agree with the team what one service covers, how portions are counted, and how the three collection streams below remain separate. Reuse the same scope/method wording for comparable dates. Put date/menu changes in their own fields. Do not include names or identifying details about individual diners. Follow existing food safety procedures; this sheet does not authorize storage or donation.

## 6. Comparing periods responsibly

Agree in advance which dates/category/site/menu and methods can be compared. Record all eligible services, including missing readings, and use consistent definitions. Report the number of services and covered measurements, plus paired unique-diner counts when available. Do not compare a weighed category with a portion estimate or mix synthetic practice with actual reports. Call any before/after result an **observational comparison — not causal evidence**. A real impact evaluation needs a separately agreed prospective design; this sheet alone cannot show prevented waste.
